# MASA 🔮

> 생년월일시로 보는 나의 사주팔자 — 웹에서 바로 확인하는 사주 풀이 앱

MASA는 태어난 날짜와 시간을 입력하면 **사주팔자(四柱八字)** 를 계산하고, 오행 분포와 일간(日干)을 바탕으로 성향·운세 풀이를 보여주는 웹 앱입니다. 별도 설치 없이 브라우저에서 바로 사용할 수 있으며, [Vercel](https://vercel.com)에 배포됩니다.

🌐 **Live Demo:** https://masa-hazel.vercel.app

---

## ✨ 주요 기능

결과는 긴 글이 아니라 **동화책**으로 펼쳐집니다. 대분류를 고르면 페이지마다 움직이는 그림 한 장과, 갓을 쓴 부엉이 **마사 선생**의 말풍선이 나와 명리 용어를 쉽게 풀어 설명해 줍니다.

기본은 **커플 사주**이고, **혼자 보기**도 고를 수 있어요. 커플 모드에서는 「💞 우리 둘의 궁합」 그림책에 더해, 카드 8장을 **우리(부부 관점) / 나 / 상대** 세 가지 관점으로 볼 수 있어요.

카드 순서는 **내년 운 → 올해 운 → 이번 달 운 → 재물운 → 연애운 → 직업운 → 부부운 → 자녀운**이에요.

| 관점 | 카드마다 들어 있는 내용 |
| --- | --- |
| 💞 우리 (각 5~6장) | 두 사람에게 온 손님(십성)과 점수 비교 → 두 사주가 만나는 방식 → 분야·월별 점수 겹쳐 보기 → **함께 해야 할 행동** → **함께 피해야 할 행동** |
| 나 · 상대 (각 5~11장) | 올해·내년 운 11장(지장간 · 네 기둥 합충 · 오행 저울 · 분야별 점수 · 월별 점수와 근거), 나머지 카드는 별이 놓인 자리 · 정/편 구분 · 지장간 · 신살 · 대운 · 올해/내년 점수까지 5~6장 |
| 💞 우리 둘의 궁합 (7장) | 천간합 · 일간 생극 · 부부궁 합/삼합/충/원진 · 잘 맞는 점 · 맞지 않는 점 · 함께 헤쳐나갈 길 · 함께 걷는 10년 |

- **입력** — 생년월일(8자리)과 태어난 시간(4자리)을 숫자로 직접 입력해요. 모바일에서는 숫자 키패드가 떠요. 입력값은 이 기기의 브라우저(localStorage)에만 저장되고, 「저장된 입력 지우기」로 지울 수 있어요.
- **그림책 연출** — 카드를 누르면 이야기 한 권이 **한 장으로 길게** 펼쳐져요(카드당 약 1,000~4,700자). 맨 위 목차로 주제를 바로 찾아가고, 주제마다 SVG 애니메이션 그림이 붙어요. 끝까지 읽고 버튼을 누르면 대분류 선택 화면으로 돌아가고 「✓ 읽음」이 표시돼요.
- **구체적인 풀이** — 일간 10개별 돈·연애·일 습관, 일지 12개별 배우자 모습, 시지 12개별 아이 성향, 십성 10개별 직업과 「해 볼 일 / 피할 일」 세 가지씩, 재물 유형별 실천 계획, 합·충이 되는 글자(띠)까지 생활 속 예시로 적어요.
- **운 점수** — 기본 60점에서 천간·지지 오행(용신 +12/+10, 희신 +7/+6, 기신 −9/−8, 과다 −6), 일지와의 합 +8 · 삼합 +5 · 충 −12 · 원진 −6, 일간 천간합 +5를 더하고 빼요. 월 점수는 그달 점수 70% + 그해 점수 30%예요. 모든 점수는 화면에 근거와 함께 보여줘요.
- **사주 원국 표** — 연·월·일·시주, 십성, 오행 분포, 신살 배지(도화·역마·화개·천을귀인·문창귀인·백호·괴강)
- **음력 · 윤달 · 시간 모름** 입력 지원, 한국 표준시 30분 보정 옵션
- **모바일 최적화** — 반응형 UI, 다크 모드, 모바일에서는 바텀시트로 열림

모든 문장은 고정 문구([`lib/story/text.ts`](lib/story/text.ts), [`lib/deck.ts`](lib/deck.ts))를 조합해 만들고, 한국어 조사(이/가 · 을/를 · 이에요/예요)는 받침에 맞춰 자동으로 붙입니다. 페이지 형식은 [`lib/story/types.ts`](lib/story/types.ts)의 `StoryPage`(제목 · 장면 · 말풍선 · 근거 배지)라서, 나중에 AI로 문장을 다듬을 때도 이 JSON만 채우게 하면 됩니다.

## 🛠 기술 스택

| 구분 | 사용 기술 |
| --- | --- |
| Framework | [Next.js](https://nextjs.org) (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS |
| 만세력 / 음양력 변환 | [lunar-javascript](https://github.com/6tail/lunar-javascript) (절기 · 입춘 · 윤달 · 대운) |
| 해석 로직 | 자체 구현 (`lib/saju/engine.ts`) |
| Deploy | Vercel |

## 📁 프로젝트 구조

```
MASA/
├── app/
│   ├── page.tsx              # 입력 폼 → 표지 → 대분류 선택
│   ├── layout.tsx
│   └── globals.css           # 색상 토큰, 그림책 스타일, 장면 애니메이션
├── components/
│   ├── BirthForm.tsx         # 생년월일시 입력
│   ├── PillarTable.tsx       # 사주 원국 표 · 오행 분포 · 신살 배지
│   └── story/
│       ├── CategoryGrid.tsx  # 대분류 그림 타일
│       ├── StoryBook.tsx     # 이야기 뷰어 (한 장 스크롤 · 목차 · 진행 표시)
│       ├── Scene.tsx         # 장면 일러스트 30여 종 (SVG 애니메이션)
│       └── Guide.tsx         # 안내자 "마사 선생" (갓 쓴 부엉이)
├── lib/
│   ├── saju/
│   │   ├── constants.ts      # 천간 · 지지 · 오행 · 십성 · 합충
│   │   ├── engine.ts         # 원국 계산 · 신강약 · 용신 · 신살 · 대운 · 세운 · 월운
│   │   ├── compat.ts         # 커플 궁합 (합 · 충 · 원진 · 보완 · 궁합 온도)
│   │   └── period.ts         # 한 해 상세 (지장간 · 네 기둥 합충 · 분야별 점수 · 월별 점수)
│   ├── story/
│   │   ├── types.ts          # Story / StoryPage / Scene 형식
│   │   ├── text.ts           # 그림책 문구 사전 + 한국어 조사 처리
│   │   ├── build.ts          # 분석 결과 → 대분류 7권
│   │   ├── couple.ts         # 궁합 → 「우리 둘의 궁합」 그림책
│   │   ├── yearly.ts         # 올해·내년 운 (십성별 분야 풀이 · 자리별 합충 예시 · 월별 근거)
│   │   ├── detail.ts         # 별의 자리 · 정/편 · 지장간 · 신살 · 대운 풀이 재료
│   │   ├── coupleCards.ts    # 부부 관점 카드 8장 (해야 할 행동 · 피해야 할 행동)
│   │   ├── rich.ts           # 일간 · 지지 · 십성별 구체적인 풀이 표
│   │   └── enrich.ts         # 이야기에 구체적인 풀이 덧붙이기
│   └── deck.ts               # 일간 · 십성 · 직업 · 개운 · 신살 고정 문구
└── types/                    # lunar-javascript 타입 선언
```

> 그림은 현재 SVG로 직접 그린 임시 일러스트입니다. 실제 일러스트가 준비되면 `Scene.tsx`에서 장면 종류(`kind`)별로 이미지를 바꿔 끼우면 됩니다.

## 🚀 시작하기

### 요구 사항

- Node.js 18 이상
- npm (또는 pnpm / yarn)

### 로컬 실행

```bash
git clone https://github.com/legnaxz/MASA.git
```

```bash
cd MASA
```

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 http://localhost:3000 을 열면 됩니다.

### 빌드

```bash
npm run build
```

```bash
npm run start
```

## ▲ Vercel 배포

1. 이 저장소를 GitHub에 푸시합니다.
2. [Vercel 대시보드](https://vercel.com/new)에서 **Import Git Repository** → `legnaxz/MASA` 선택
3. Framework Preset이 **Next.js**로 자동 인식되는지 확인
4. 환경 변수가 있다면 **Settings → Environment Variables** 에 추가
5. **Deploy** 클릭

이후 `main` 브랜치에 푸시하면 자동으로 프로덕션 배포되고, PR마다 Preview 배포가 생성됩니다.

CLI로 배포하려면:

```bash
npx vercel --prod
```

## 📖 사주 계산 방식

- **연주** — 입춘(立春)을 기준으로 해가 바뀝니다.
- **월주** — 24절기 중 12절(節)을 기준으로 월이 바뀝니다.
- **일주** — 기준일로부터 60갑자 순환으로 계산합니다.
- **시주** — 태어난 시각을 12지지 시간대(2시간 단위)로 나누고, 일간에 따라 시간(時干)을 정합니다.
- 한국 표준시(KST)와 실제 태양시의 차이(약 30분)는 옵션으로 보정할 수 있습니다.
- **신강/신약 · 용신**은 억부법을 단순화한 간이 판단입니다 (월지 가중치 2, 일간을 돕는 오행 비율 50% 이상이면 신강). 조후 · 격국은 아직 반영하지 않았습니다.
